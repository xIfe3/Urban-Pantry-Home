📝 Creating a New Admin Account

Follow these simple steps to add a new admin user to Urban Pantry.

Step 1: Go to Admin Users

  1. Click on "Staff & Access" section in the dashboard
  2. Click the "Add" button next to "Admin users"
  3. Or navigate to: Create a new user →

Step 2: Fill in User Information

  • Username: Enter a unique username (e.g., john_admin, sarah_team)
  • Password: Click "Generate" for a secure password or create one yourself
  • Confirm Password: Re-enter the password to confirm

Step 3: Set Admin Permissions

Scroll down and check the following boxes:

Staff status

✓ Check this - allows access to admin panel

Superuser status

✓ Check this - gives full admin permissions (optional, for senior admins)

💡 Tip: For regular admins, just check "Staff status". Only check "Superuser status" for trusted administrators.

Step 4: Assign Permissions (Optional)

You can set specific permissions for the new admin:

  • Can add: Allow them to create new items
  • Can change: Allow them to edit existing items
  • Can delete: Allow them to delete items
  • Can view: Allow them to view items (no editing)

💡 Tip: Superusers have all permissions by default. Staff users need specific permissions assigned.

Step 5: Save

Click the "Save" button at the bottom right.

✅ The new admin user is now created! They can log in using their username and password at /admin/
